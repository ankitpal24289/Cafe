# The Global Table — website refresh

This refresh is built directly from the original uploaded `index.html`. The original page sections, copy, menu data, cart, account flow, admin interface, theme toggle, scroll animations and location details are retained. The changes are focused on replacing embedded/placeholder food imagery with local premium category photographs and adding a responsive food-photo treatment to the existing hero.

## Run locally
1. Extract the ZIP.
2. Keep the `assets` folder beside `index.html`.
3. Open `index.html` in a modern browser, or serve this folder with VS Code Live Server.

## Notes
- The images are stored locally in `assets/`; an internet connection is not needed for the images. Google Fonts and the existing Three.js CDN remain external dependencies.
- The original front-end data/storage approach is unchanged; this is not a production backend.
